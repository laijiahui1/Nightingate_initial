Nightingale — Care Note — Attribution
======================================

Nightingale is a 72-hour hackathon build: a shared, longitudinal patient
"Care Note" clinic web application with role-based collaboration, AI-scribed
notes with deterministic No-PHI redaction, span-stable provenance, and a
glanceable Top Card.

Security model
    - Row-Level Security is enforced natively by PostgreSQL (FORCE ROW LEVEL
      SECURITY + role-scoped policies). No third-party authorization library
      is used for RLS; the SECURITY DEFINER functions and policies are
      hand-authored in backend/app/db/rls.sql.

AI-assisted development
-----------------------
This codebase was generated and orchestrated with Claude Code (Anthropic)
under a multi-agent workflow during a single overnight session. The
requirements breakdown, architecture, SQL/RLS policies, API routes, tests,
and frontend were authored by Claude Code agents; the human team member
specified the product, chose the stack, and reviewed the milestone commits.

The "AI Scribe" feature routes note text through a bundled mock LLM service
(backend/services/mock_llm.py) — no external model API is called in this
demo. All redaction is deterministic and local (regex + lexicon); an LLM is
never used to redact.

Mock data
---------
All patients, staff, clinicians, notes, and PHI patterns are synthetic and
seeded (backend/app/seed.py). Any resemblance to real persons is coincidental.
